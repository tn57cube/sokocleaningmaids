# Soko Cleaning Maids Ltd — Website

A simple, responsive website for Soko Cleaning Maids Ltd, a cleaning service based in North Lanarkshire, UK.

## Pages

- **Home** (`index.html`) — landing page with hero section and call to action
- **About** (`about.html`) — company info
- **Services** (`services.html`) — list of cleaning services offered
- **Contact** (`contact.html`) — contact details, map, and enquiry form
- **Blog** (`blog.html`) — blog posts and comments (via Giscus)

## Features

- Responsive layout with a mobile-friendly slide-out nav menu
- Embedded Google Map showing the service area
- Contact form powered by [FormSubmit](https://formsubmit.co/) — no backend required
- Click-to-call and click-to-email links, plus WhatsApp, Facebook, and Instagram icons
- Icon hover effects for a bit of polish

## Built With

- HTML5 & CSS3
- [Font Awesome](https://fontawesome.com/) for icons
- [Google Fonts](https://fonts.google.com/) (Montserrat, Nunito, Open Sans, Roboto, Roboto Slab)
- [Giscus](https://giscus.app/) for blog comments

## Running Locally

No build step needed — it's plain HTML/CSS.

1. Clone or download this repository
2. Open `index.html` in your browser
